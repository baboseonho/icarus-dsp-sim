# 2회차 · 기울여서 원하는 곳으로

[English](README.en.md)

드론은 기울여야 옆으로 간다. 1회차 PID를 x, y, z 세 축에 쓰고, 원하는 가속도를 추력과 기울기로 바꾸는
드론 칩의 제어기를 직접 만든다. 수업이 끝나면 내 칩이 바람 속에서 5 cm 안에 머물고, 웨이포인트 다섯 개를 돌고, 원을 따라간다.

## 수업 시작하기

```bash
dsp          # 저장소로 가서 환경 불러오기
git pull     # 오늘 회차 받기
code .
```

VS Code에서 `week02/lesson.ipynb`를 연다. 오른쪽 위 커널이 `ICARUS DSP (py3.12)`인지 확인한다.
커널을 고르라고 하면 `Jupyter Kernel…` 목록에서 `ICARUS DSP (py3.12)`를 고른다.
첫 셀을 `Shift+Enter`로 실행해서 "시뮬레이터 준비 완료"가 나오면 된다.
영어 노트북은 `week02/lesson_en.ipynb`이다 (내용과 빈칸은 같고 설명만 영어).

## 수업 방식

- 1회차와 같다. `✍️` 셀에서 같이 코드를 치고 `Shift+Enter`로 바로 그래프를 본다. 빈칸은 `___`.
- 오늘 만드는 ①②③은 드론 칩 안에서, ④는 지상국(노트북)에서 돈다.
- 단계마다 손으로 푼 답과 비교하는 표가 나온다. 실행하기 전에 답을 먼저 맞혀 보고, 초록이면 다음으로 넘어간다.
- 칩이 완성되면(5단계) 바로 실시간 비행으로 넘어가서, 날고 있는 드론의 목표, 게인, 바람을 직접 바꿔 본다.

| 단계 | 같이 칠 것 | 바로 볼 것 |
|---|---|---|
| 0 준비 | 없음 | 1회차 PID를 세 축에 한꺼번에, numpy 몸풀기 |
| 1 기울기 | `g * tan(θ)` | 기울인 채 날리기, 공기 저항 |
| 2 ① 위치 제어기 | 위치·속도 오차, 출력 | 손으로 푼 세 입력과 비교 |
| 3 ② 추력과 자세 | 힘, pitch, roll, 추력 (yaw 회전은 채워 둠) | 힘 그림, 네 입력과 비교, 20 m/s²면 64° |
| 4 ③ 기울기 제한 | `if` 조건과 비율 | 64° → 30° |
| 5 첫 비행 | 없음 (칩 조립) | 바람 속 호버, PID와 PD 비교 |
| 6 실시간 비행 | 없음 | 날면서 목표, 게인, 바람, 원 그리기 바꾸기 / PlotJuggler |
| 7 ④ 웨이포인트 | 도착 판정 | 링 코스 경로, 기울기, 영상 |
| 8 원과 앞먹임 | 없음 (같이 보기) | 앞먹임 켬/끔 비교 |
| 9 미션 | 없음 (게인 바꿔 보기) | 네 칸 초록 / 슬라이더 |
| 집에서 칼만 필터 | 예측, 이득, 보정 (선택) | 카메라 그대로 vs 칼만 필터의 추력 떨림 |

미션 기준 (기본 게인 kp 6, kd 4, ki 2): 바람 속 호버 위치 오차 RMS < 5 cm, 링 코스 5/5를 40초 안에 최대 기울기 35° 이하로, 원 궤적 RMS < 10 cm.
