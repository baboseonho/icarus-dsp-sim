# 1회차 · 한 대를 띄우는 피드백

[English](README.en.md)

드론 한 대를 위아래로만 움직이게 두고, 높이를 보면서 추력을 고치는 PID를 직접 써 본다.
수업이 끝나면 내 PID가 드론을 0.5 m에서 1.5 m로 올려서 그 자리에 세운다.

## 수업 전에 한 번 확인하기

설치를 미리 끝냈다면, 수업 전에 터미널(`Ctrl+Alt+T`)에서 아래 두 줄을 실행해 본다.
터미널에는 명령만 친다. `#` 뒤는 설명이라 치지 않는다.

```bash
dsp              # 저장소 폴더로 이동하고 환경 불러오기
git remote -v    # 이 폴더가 어디서 받은 것인지 확인
```

| 나온 결과 | 뜻 | 할 일 |
|---|---|---|
| `origin  https://github.com/baboseonho/icarus-dsp-sim.git` | 정상 | 없음. 수업 날 아래 "수업 시작하기"대로 하면 된다 |
| `fatal: not a git repository` | ZIP으로 받은 폴더라 `git pull`이 안 된다 | 아래 "다시 받기"를 한 번 실행한다 |
| `dsp: command not found` | 설치가 끝나지 않았거나 예전 터미널이다 | 터미널을 새로 열어 다시 해 본다. 그래도 안 되면 저장소 README의 "1. 설치"부터 한다 |

**다시 받기** (ZIP으로 받았던 사람만, 처음 한 번)

```bash
mv ~/icarus-dsp-sim ~/icarus-dsp-sim_old
git clone https://github.com/baboseonho/icarus-dsp-sim.git ~/icarus-dsp-sim
cd ~/icarus-dsp-sim && bash setup/install.sh --no-sudo
```

`--no-sudo`는 이미 깔린 시스템 설치(ROS 등)는 건너뛰고 Python 환경과 `dsp` 별칭만 다시 만든다. 몇 분이면 끝난다.
Ubuntu는 24.04와 26.04 모두 된다.

## 수업 시작하기

```bash
dsp          # 저장소로 가서 환경 불러오기 (설치할 때 만든 별칭)
git pull     # 오늘 회차 폴더(week01/) 받기
code .       # VS Code로 저장소 열기
```

VS Code에서 `week01/lesson.ipynb`를 연다. 오른쪽 위 커널이 `ICARUS DSP (py3.12)`인지 확인한다.
커널을 고르라고 하면 `Jupyter Kernel…` 목록에서 `ICARUS DSP (py3.12)`를 고른다.
첫 셀을 `Shift+Enter`로 실행해서 "시뮬레이터 준비 완료"가 나오면 된다.

## 수업 방식

- 설명을 듣다가 `✍️` 표시가 있는 셀에서 같이 코드를 친다. 빈칸은 `___`.
- `Shift+Enter`로 셀을 실행하면 바로 그래프가 나온다.
- 숫자(`kp`, `kd`, `ki` 등)를 바꿔서 다시 실행하고, 그래프가 어떻게 바뀌는지 본다.
- 빈칸을 안 채우고 실행하면 `✍️ 아직 채우지 않은 빈칸(___)이 있어요`가 뜬다.
- 단계마다 앞 단계 코드가 미리 채워져 있어서, 한 번 놓쳐도 다음 단계부터 다시 따라오면 된다.

| 단계 | 같이 칠 것 | 바로 볼 것 |
|---|---|---|
| 0 준비 | 없음 | 기체 정보 |
| 1 호버 추력 | 떠 있는 데 필요한 추력 | 정확할 때 / 10% 무거울 때 / 가벼울 때 |
| 2 P 제어 | 오차, P 출력 | 출렁이고 처지는 계단 응답, `kp` 2·8·20 비교 |
| 3 D 제어 | 미분, 출력 | P와 PD 비교, `kd` 2·4·8 비교 |
| 4 I 제어 | 적분, 출력 | 처짐이 사라지고 대신 지나침 |
| 5 가까울 때만 적분 | `if` 조건 한 줄 | 지나침이 줄어드는 것 |
| 6 미션 | 내 게인 숫자 | 여섯 칸 초록 / 슬라이더로 바로 바꿔 보기 |
| 7 실시간 비행 | 없음 | 날고 있는 동안 목표와 게인 바꾸기, PlotJuggler로 보기 (선택) |

미션 기준: 오버슈트 < 10%, 2% 정착 < 2초, 마지막 1초 오차 < 2 cm. 질량이 맞는 기체와 10% 무거운 기체 모두.
